Getting Started: Vivado & the Basys 3

Create your first Vivado project, assign pins with a constraints file, and light up real LEDs on the Basys 3 board — the complete flow, start to finish.

The big picture

An FPGA is a chip full of uncommitted logic — thousands of tiny look-up tables (each one literally a truth table), flip-flops, and programmable wiring. Verilog describes the circuit you want; Vivado turns that description into a configuration file (a bitstream) and loads it onto the Basys 3 board. Every design in this course follows the same five-stage flow:

  • Design — write Verilog source files (.v).
  • Simulate — verify behavior in software before touching hardware (Tutorial 4).
  • Synthesize — Vivado converts Verilog into a netlist of FPGA primitives.
  • Implement — place the netlist onto the chip and route the wires; pin locations come from your constraints (.xdc) file.
  • Program — generate the bitstream and send it to the board over USB.

Create the project

  1. Open Vivado and choose Create Project. Name it lab1_hello, pick a folder with no spaces in the path, and keep "Create project subdirectory" checked.
  2. Select RTL Project and check Do not specify sources at this time.
  3. On the part-selection screen, click the Boards tab and choose Basys 3. If it isn't listed, click Refresh / Install/Update Boards, or select the part directly: xc7a35tcpg236-1.
  4. Finish. You land in the Flow Navigator (left panel) — it lists the five stages in order, top to bottom.
  5. Add a source: Sources panel → + → Add or create design sources → Create File, name it top. Skip the port wizard (click OK, then Yes) — we'll type the ports ourselves.

Your first module

This design wires four slide switches straight to four LEDs — no logic yet, just a connection. It proves the whole toolchain works.

top.v
// Four switches drive four LEDs.
module top(
    input  wire [3:0] sw,    // slide switches SW3..SW0
    output wire [3:0] led    // LEDs LD3..LD0
);
    assign led = sw;         // continuous connection
endmodule

Don't worry about the syntax details yet — Tutorial 2 explains every line. The key idea: assign creates a permanent wire between the two, like soldering.

Pin assignments: the XDC file

Verilog says what the circuit does; the constraints file says where its ports connect on the physical chip. Digilent publishes a master XDC for the Basys 3 with every pin pre-written and commented out — you uncomment the lines you use and make the port names match your module.

  1. Download Basys-3-Master.xdc from Digilent's website (search "Basys 3 master XDC").
  2. Sources → + → Add or create constraints → Add Files, select the XDC.
  3. Uncomment the four sw lines and four led lines. Port names in the XDC must match your Verilog port names exactly (they already do if you used sw and led).
Basys-3-Master.xdc (excerpt — sw[0] and led[0])
## Switches
set_property PACKAGE_PIN V17 [get_ports {sw[0]}]
    set_property IOSTANDARD LVCMOS33 [get_ports {sw[0]}]

## LEDs
set_property PACKAGE_PIN U16 [get_ports {led[0]}]
    set_property IOSTANDARD LVCMOS33 [get_ports {led[0]}]

PACKAGE_PIN names the physical ball on the chip (switch SW0 is wired to pin V17 on the board); IOSTANDARD LVCMOS33 sets the voltage standard (3.3 V) — every Basys 3 I/O in this course uses it.

Most common Lab 1 error: a port name mismatch between the XDC and the module (LED vs led, or uncommenting sw[15:4] lines you don't use). Implementation fails with "unconstrained logical port" or "port not found." Names are case-sensitive.

Build and program

  1. Click Generate Bitstream in the Flow Navigator — Vivado runs synthesis and implementation automatically first. First runs take a few minutes.
  2. Connect the Basys 3 by USB, power switch ON (the mode jumper JP1 should be on JTAG).
  3. Open Hardware Manager → Open Target → Auto Connect.
  4. Program Device → select the generated .bit file → Program.
  5. Flip switches SW0–SW3. The LEDs above them should follow. 🎉
