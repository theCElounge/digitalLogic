Modules, Wires & Dataflow Modeling

The anatomy of a Verilog module: ports, wires, operators, vectors, and building bigger circuits from smaller ones — culminating in a 4-bit adder.

Anatomy of a module

A module is Verilog's unit of hardware — a box with input and output ports. Everything you build in this course is a module or a combination of modules.

Module skeleton
module my_circuit(
    input  wire a,       // 1-bit input
    input  wire b,
    output wire y        // 1-bit output
);
    // circuit description goes here
    assign y = a & b;    // y is ALWAYS a AND b
endmodule
  • wire is a physical connection — it has no memory, it just carries a value.
  • assign creates continuous assignment: the right side is constantly evaluated, like real gates. It is not a one-time assignment like in C or Python.
  • Statements describe hardware existing in parallel, not steps executing in order. Two assign lines are two circuits operating at the same time.

Operators = gates

Dataflow modeling describes logic with operators. Each operator synthesizes to the gate you studied in the Logic Gates lesson:

GateBooleanVerilogExample
ANDa·b&assign y = a & b;
ORa+b|assign y = a | b;
NOTa′~assign y = ~a;
XORa⊕b^assign y = a ^ b;
NAND(a·b)′~(&)assign y = ~(a & b);
NOR(a+b)′~(|)assign y = ~(a | b);

Any SOP expression from a K-map translates directly. The minimized majority voter F = ab + bc + ac becomes:

Majority voter — straight from the K-map
module majority(
    input  wire a, b, c,
    output wire f
);
    assign f = (a & b) | (b & c) | (a & c);
endmodule

Vectors: buses of bits

Square brackets declare multi-bit signals. [3:0] is a 4-bit bus, bit 3 is the most significant.

Vector essentials
wire [3:0] a;              // 4-bit bus: a[3] a[2] a[1] a[0]
wire [7:0] big;

assign big = {a, 4'b0000}; // concatenation: a shifted into the top half
assign y   = a[2];         // bit select
assign lo  = a[1:0];       // part select (2 bits)

// Sized literals:  <width>'<base><value>
// 4'b1010  = 4-bit binary 1010     (decimal 10)
// 8'hF3    = 8-bit hex F3
// 4'd9     = 4-bit decimal 9

Hierarchy: modules inside modules

Real designs are built by instantiating tested sub-modules — exactly how you built a full adder from two half adders on paper. Always connect ports by name (.port(signal)); positional connection invites silent bugs.

full_adder.v — structural design from half adders
module half_adder(
    input  wire a, b,
    output wire s, c
);
    assign s = a ^ b;
    assign c = a & b;
endmodule

module full_adder(
    input  wire a, b, cin,
    output wire s, cout
);
    wire s1, c1, c2;

    half_adder ha0 (.a(a),  .b(b),   .s(s1), .c(c1));
    half_adder ha1 (.a(s1), .b(cin), .s(s),  .c(c2));

    assign cout = c1 | c2;
endmodule

Chain four of them and you have the Lab 5 ripple-carry adder:

adder4.v — 4-bit ripple-carry adder
module adder4(
    input  wire [3:0] a, b,
    input  wire       cin,
    output wire [3:0] sum,
    output wire       cout
);
    wire c1, c2, c3;

    full_adder fa0 (.a(a[0]), .b(b[0]), .cin(cin), .s(sum[0]), .cout(c1));
    full_adder fa1 (.a(a[1]), .b(b[1]), .cin(c1),  .s(sum[1]), .cout(c2));
    full_adder fa2 (.a(a[2]), .b(b[2]), .cin(c2),  .s(sum[2]), .cout(c3));
    full_adder fa3 (.a(a[3]), .b(b[3]), .cin(c3),  .s(sum[3]), .cout(cout));
endmodule
  • Shortcut for later: once you understand the structure, Verilog lets you write the whole thing as assign {cout, sum} = a + b + cin; — the synthesizer builds the adder for you. In Lab 5 you build it from full adders first, on purpose.
