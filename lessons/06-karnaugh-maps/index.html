What Is a Karnaugh Map?

A Karnaugh map (K-map) is a graphical tool for simplifying Boolean expressions. It takes a truth table and rearranges it into a grid where every cell holds one minterm — but the rows and columns are ordered so that any two neighboring cells differ in exactly one input variable.

Each cell holds a 1 where the function is true, a 0 where it’s false, and sometimes an X for a “don’t care” — an input combination whose output doesn’t matter. Once the map is filled in, the simplification becomes a pattern-spotting exercise: you circle rectangular blocks of adjacent 1s, and each block turns directly into a simplified term.

Why Are K-Maps Needed?

A truth table gives you a function as a raw sum of minterms — one product term per row where the output is 1. That expression is almost always larger than it needs to be, and simplifying it by hand with Boolean algebra (absorption, consensus, De Morgan’s) is easy to get wrong and hard to know when you’re actually done.

Key idea: because adjacent K-map cells differ in only one variable, any rectangular group of 2, 4, 8… adjacent 1s corresponds to a term where the differing variable(s) simply drop out. Bigger group, simpler term — and it’s always correct.

Fewer terms and literals mean fewer logic gates, less propagation delay, and less power — and for 2–4 variables, a K-map finds the minimum sum-of-products almost as reliably as an algorithm, without the paperwork of Quine–McCluskey.

How Karnaugh Maps Work

The whole trick is Gray-code ordering: instead of counting 00, 01, 10, 11, the headers are ordered so only one bit changes between neighbors.

Gray-code sequence for 2 bits: 00 → 01 → 11 → 10 → back to 00. Every step flips exactly one bit — including the wraparound step from 10 back to 00.

Because of that ordering:

  • Cells that are horizontally or vertically next to each other differ in exactly one variable.
  • The map wraps around: the leftmost column is adjacent to the rightmost column, and the top row is adjacent to the bottom row — it behaves like the surface of a torus, not a flat sheet.
  • Diagonal neighbors are not adjacent — they differ in two variables at once.

Rules for Grouping

  1. Only combine 1s (and don’t cares). Never group a 0 — but you may treat an X as a 1 when it helps form a bigger group, or ignore it when it doesn’t.
  2. Group sizes must be a power of 2 — 1, 2, 4, 8, 16 cells. Never 3, 5, or 6.
  3. Groups must be rectangular, including wraparound across an edge — never an L-shape or other irregular outline.
  4. Make groups as large as possible. A bigger group eliminates more variables and gives a simpler term.
  5. Groups may overlap. The same 1 can belong to more than one group if that lets each group be as large as possible.
  6. Every 1 must be covered by at least one group — none can be left out.
  7. Use the minimum number of groups needed to cover every 1, since fewer groups means fewer terms in the final expression.
  8. Don’t cares are optional helpers. Use an X only when it lets you form a larger group; you never need to cover an X on its own.
  9. Read each group as a product term: keep only the variables that stay constant across the whole group (0 → complemented, 1 → uncomplemented); drop any variable that varies within the group.
  10. OR all the group terms together for the final simplified sum-of-products expression.

Common mistakes: circling a group of 3 or 6 cells, treating diagonal cells as adjacent, or forgetting that the map wraps top-to-bottom and left-to-right.

Two-Variable K-Maps

4 cells (2²), one per combination of A and B.

Example 1. F(A,B) = Σ(0, 1, 3)
A \ B01
01m01m1
10m21m3
  • Top row (m0, m1): A = 0 stays constant → A′
  • Right column (m1, m3): B = 1 stays constant → B

F = A′ + B

Example 2. F(A,B) = Σ(1, 2)
A \ B01
00m01m1
11m20m3

The two 1s sit diagonally from each other — not adjacent — so neither can be grouped into a pair. Each stays a full two-variable term.

F = A′B + AB′

Example 3. F(A,B) = Σ(0, 1, 2, 3)
A \ B01
01m01m1
11m21m3
  • All four cells: one group of 4 — both variables drop out

F = 1

Three-Variable K-Maps

8 cells (2³). Variable A forms the rows; B and C form the columns in Gray-code order.

Example 4. F(A,B,C) = Σ(0, 1, 2, 3, 5, 7)
A \ BC00011110
0 1m0 1m1 1m3 1m2
1 0m4 1m5 1m7 0m6
  • Whole top row (m0, m1, m3, m2): A = 0 constant → A′
  • Middle two columns, both rows (m1, m5, m7, m3): C = 1 constant → C

Cells m1 and m3 belong to both groups — overlap is allowed and often unavoidable.

F = A′ + C

Example 5. F(A,B,C) = Σ(1, 3, 5, 7)
A \ BC00011110
0 0m0 1m1 1m3 0m2
1 0m4 1m5 1m7 0m6
  • Middle two columns, both rows: only C stays constant (C = 1)

F = C

Example 6. F(A,B,C) = Σ(0, 2, 4, 5, 6)
A \ BC00011110
0 1m0 0m1 0m3 1m2
1 1m4 1m5 0m7 1m6
  • Outer two columns (00 and 10), both rows — wraps around the map’s edges: C = 0 constant → C′
  • m4 and m5 (row A = 1, columns 00 and 01): A = 1, B = 0 constant → AB′

F = C′ + AB′

Four-Variable K-Maps

16 cells (2⁴). A and B form the rows, C and D form the columns, both in Gray-code order. This map wraps both left-right and top-bottom.

Example 7. F(A,B,C,D) = Σ(0, 1, 2, 3, 7, 11, 15)
AB \ CD00011110
00 1m0 1m1 1m3 1m2
01 0m4 0m5 1m7 0m6
11 0m12 0m13 1m15 0m14
10 0m8 0m9 1m11 0m10
  • Whole top row (m0, m1, m3, m2): A = 0, B = 0 constant → A′B′
  • Whole CD = 11 column, all four rows: C = 1, D = 1 constant → CD

F = A′B′ + CD

Example 8. F(A,B,C,D) = Σ(0, 4, 8, 12, 13, 14, 15)
AB \ CD00011110
00 1m0 0m1 0m3 0m2
01 1m4 0m5 0m7 0m6
11 1m12 1m13 1m15 1m14
10 1m8 0m9 0m11 0m10
  • Whole CD = 00 column, all four rows — wraps top-to-bottom: C = 0, D = 0 constant → C′D′
  • Whole AB = 11 row: A = 1, B = 1 constant → AB

F = C′D′ + AB

Example 9. F(A,B,C,D) = Σ(1, 3, 5, 7, 9) + d(11, 13, 15)
AB \ CD00011110
00 0m0 1m1 1m3 0m2
01 0m4 1m5 1m7 0m6
11 0m12 Xm13 Xm15 0m14
10 0m8 1m9 Xm11 0m10
  • Both CD = 01 and CD = 11 columns, all four rows, treating the X’s as 1s: only D stays constant (D = 1)

Without the don’t cares, the same five 1s could only be grouped into smaller pairs. Letting the map fill in the X’s at m11, m13, and m15 collapses the whole function to a single variable.

F = D
