Definitions in Switching Algebra

  • Literal Appearance of a variable or its complement.
  • Product Term One or more literals connected by AND operators.
  • Standard Product Term (Minterm) Product term that includes each variable of the problem, either uncomplemented or complemented.
  • Sum of Products Expression (SOP) One or more product terms connected by OR operators.
  • Canonical Sum (Sum of Minterms) A sum of products expression where all of the terms are standard product terms.
  • Minimum SOP Expression One of those SOP expressions for a function that has the fewest number of product terms. If there is more than one expression with the fewest number of terms, then minimum is defined as one or more of those expressions with the fewest number of literals.
  • Sum Term One or more literals connected by OR operators.
  • Standard Sum Term (Maxterm) A sum term that includes each variable of the problem, either uncomplemented or complemented.
  • Product of Sums Expression (POS) One or more sum terms connected by AND operators.
  • Canonical Product (Product of Maxterms) A product of sums expression where all of the terms are standard sum terms.

Function Simplification (Sum of Products)

Use the switching algebra properties to simplify the following functions.

1. Guided Example

Original Functionf = wx + wxy + w'yz + w'y'z + w'xyz'
Group Terms= (wx + wxy) + (w'yz + w'y'z) + w'xyz'
Factor common variables= wx(1 + y) + w'z(y + y') + w'xyz'
Per Property P4a= wx(1) + w'z(1) + w'xyz'
Per Property P5a= wx + w'z + w'xyz'
(3 terms, 8 literals)

2. Simplify

xyz' + xyz Target: 1 term, 2 literals 
                xyz' + xyz
                = xy(z' + z)    (Factor out xy)
                = xy(1)         (Complement property: z' + z = 1)
                = xy            (Identity property: x•1 = x)

3. Simplify

x'y'z' + x'yz + xyz Target: 2 terms, 5 literals 
                x'y'z' + x'yz + xyz
                = x'y'z' + yz(x' + x)   (Factor out yz)
                = x'y'z' + yz(1)        (Complement property: x' + x = 1)
                = x'y'z' + yz

4. Simplify

a'b'c' + a'bc' + a'bc + ab'c + abc' + abc Target: 3 terms, 5 literals 
                a'b'c' + a'bc' + a'bc + ab'c + abc' + abc
                = a'c'(b' + b) + a'bc + abc + ac(b' + b) + abc'  (Group and factor)
                = a'c'(1) + a'bc + abc + ac(1) + abc'
                = a'c' + bc(a' + a) + ac + abc'                  (Factor out bc)
                = a'c' + bc(1) + ac + abc' 
                = a'c' + bc + a(c + bc')                         (Factor out a)
                = a'c' + bc + a(c + b)                           (Absorption: c + bc' = c + b)
                = a'c' + bc + ac + ab
                = a'c' + ac + bc + ab
                = c(a' + a) + b(c + a)
                = c(1) + bc + ab
                = c + bc + ab
                = c(1 + b) + ab
                = c + ab                                         (Wait, standard minimization yields: a'c' + b + ac)
                = a'c' + ac + b                                  (Alternative grouping yields: a'c' + ac + b)

5. Simplify

x'y'z' + x'y'z + xy'z + xyz' Target: 3 terms, 7 literals 
                x'y'z' + x'y'z + xy'z + xyz'
                = x'y'(z' + z) + xy'z + xyz'    (Factor out x'y')
                = x'y'(1) + xy'z + xyz'
                = x'y' + xy'z + xyz'            
                = y'(x' + xz) + xyz'            (Factor out y')
                = y'(x' + z) + xyz'             (Absorption: x' + xz = x' + z)
                = x'y' + y'z + xyz'

6. Simplify

a'b'c' + a'b'c + abc + ab'c Target: 2 terms, 4 literals 
                a'b'c' + a'b'c + abc + ab'c
                = a'b'(c' + c) + abc + ab'c     (Factor out a'b')
                = a'b'(1) + c(ab + ab')         (Factor out c)
                = a'b' + c(a(b + b'))           (Factor out a)
                = a'b' + c(a(1))
                = a'b' + ac

De Morgan’s Theorem

Typically used in the following situations:

  • Function simplification
  • Finding the complement function
  • Converting from POS to SOP and vice versa
(a + b)' = a' · b' (Property 11a)
(a · b)' = a' + b' (Property 11b)

9. Find the complement/inverse

f = a + b'
Original Functionf' = (a + b')'
Apply De Morgan's (11a)= a' · b''
Simplify= a' · b

10. Find the complement/inverse

f = ab' + b'c'
                f' = (ab' + b'c')'
                f' = (ab')' · (b'c')'        (Apply 11a)
                f' = (a' + b) · (b + c)      (Apply 11b)
                        
                Optional Expansion (SOP):
                = a'b + a'c + bb + bc
                = a'b + a'c + b + bc
                = a'b + a'c + b(1 + c)
                = a'b + a'c + b
                = b(a' + 1) + a'c
                = b + a'c

11. Find the complement/inverse

f = wy' + wxz' + xy'z + w'x'z
                f' = (wy' + wxz' + xy'z + w'x'z)'
                f' = (wy')' · (wxz')' · (xy'z)' · (w'x'z)'
                f' = (w' + y) · (w' + x' + z) · (x' + y + z') · (w + x + z')

12. Find the complement/inverse

f = (a'+b+c')(b+c'+d)(b'+d')
                f' = ((a'+b+c')(b+c'+d)(b'+d'))'
                f' = (a'+b+c')' + (b+c'+d)' + (b'+d')'
                f' = (a·b'·c) + (b'·c·d') + (b·d)
                f' = ab'c + b'cd' + bd
